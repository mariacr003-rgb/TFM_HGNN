Objetivo: Descargar una muestra real de 20 ficheros de RNA-seq de la cohorte TCGA-LUAD desde el portal GDC y convertirla a una tabla unica, replicando exactamente el mismo pipeline ya verificado con TCGA-BRCA (Paso 2), como primer dato real de la primera de las 4 cohortes pendientes.

Entrada:
- data/raw/luad_manifest_full.txt (manifest completo de 36.224 ficheros del proyecto TCGA-LUAD, descargado via API REST del GDC en el Paso 6)

Comando:
  python src/02_filtrar_manifest.py data/raw/luad_manifest_full.txt data/raw/manifest_rnaseq_luad_20.txt 20
  mkdir -p data/raw/rnaseq_luad
  tools/gdc-client.exe download -m data/raw/manifest_rnaseq_luad_20.txt -d data/raw/rnaseq_luad
  python src/03_convertir_rnaseq.py data/raw/rnaseq_luad data/raw/LUAD_rnaseq.tsv

Ningun script se modifico: src/02_filtrar_manifest.py y src/03_convertir_rnaseq.py son genericos (reciben rutas por linea de comandos, sin nombre de cohorte hardcodeado) y se reutilizaron tal cual, ya usados en el Paso 2 para BRCA.

Salida:
- data/raw/manifest_rnaseq_luad_20.txt (lista de los 20 ficheros seleccionados)
- data/raw/rnaseq_luad/ (20 subcarpetas con ficheros .tsv reales descargados)
- data/raw/LUAD_rnaseq.tsv (19962 genes x 20 pacientes)

Commit: (pendiente, se anadira en un commit de seguimiento, igual que se hizo en los runlogs de los pasos 1 y 5)

Resultado obtenido:
19962 genes protein_coding x 20 pacientes reales de TCGA-LUAD, misma estructura exacta que data/raw/BRCA_rnaseq.tsv (19962 genes x 20 pacientes; 19963 lineas, 21 columnas en ambos ficheros).

Observaciones:
- Primer intento de descarga fallido: tools/gdc-client.exe no crea automaticamente el directorio de destino si no existe. Error obtenido: "Unable to write to download to directory 'data/raw/rnaseq_luad': [Errno 2] No such file or directory: 'data/raw/rnaseq_luad\tmp...'". Este es el mismo problema ya conocido de la descarga original de BRCA (Paso 2). Solucion: crear el directorio manualmente con "mkdir -p data/raw/rnaseq_luad" antes de lanzar el comando de descarga. Se repite aqui como recordatorio explicito para las proximas 3 cohortes (LUSC, COAD, KIRC).
- Se confirmo previamente (antes de este paso) que tools/gdc-client.exe (binario Windows, version 2.3) se ejecuta correctamente desde este entorno WSL mediante "tools/gdc-client.exe --version".

Es regenerable con el comando "python src/02_filtrar_manifest.py data/raw/luad_manifest_full.txt data/raw/manifest_rnaseq_luad_20.txt 20" documentado mas arriba en este mismo runlog.
