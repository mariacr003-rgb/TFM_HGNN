Objetivo: Consolidar en src/, como scripts numerados y reutilizables (argumentos por linea de comandos, sin rutas fijas), los 4 mecanismos ad-hoc usados durante los Pasos 24-29 para coordinar pacientes entre RNA-seq, CNV y metilacion (consulta a la API del GDC, calculo de interseccion, generacion de manifests, verificacion). Hasta ahora vivian solo en el directorio temporal de la sesion, sin versionar, y se reutilizaban copiando ficheros (cp) de una cohorte a otra. Se aprovecha ademas para corregir una limitacion real de la herramienta de verificacion: la version ad-hoc usada en los Pasos 25-28 solo comprobaba que el case_id coincidiera entre las 3 tablas, no que el tipo de muestra fuera "Primary Tumor" consistente — por eso no detecto por si sola el problema de BRCA (Paso 29), que se descubrio con una comprobacion mas profunda hecha aparte, por heredoc de Python, sin guardar como script.

Scripts creados en src/:

1. src/14_mapear_case_id.py (a partir de mapear_case_id_v2.py, sesion ad-hoc)
   Consulta la API REST del GDC (POST /files, lotes de 500 file_id) para resolver, a partir de una lista de ficheros candidatos (file_id + filename, 2 columnas sin cabecera), su case_id (cases.submitter_id) y tipo de muestra (cases.samples.sample_type). Uso:
     python src/14_mapear_case_id.py <lista_file_id_filename.tsv> <salida.tsv>
   La version v1 (mapear_case_id.py, sin el campo sample_type) quedo obsoleta nada mas crearse en el Paso 25 al descubrir que hacia falta tambien el tipo de muestra; se ha descartado, no se ha guardado en el repositorio.

2. src/15_interseccion_pacientes.py (a partir de interseccion_v2.py, sesion ad-hoc)
   A partir de la salida de 3 ejecuciones del script anterior (RNA-seq, CNV, metilacion), filtra a muestra "Primary Tumor", desempata los casos con mas de 1 fichero candidato (prioridad de pipeline plana>ascat3>absolute_liftover solo en CNV, despues file_id alfabeticamente menor) y calcula la interseccion de pacientes con las 3 modalidades disponibles. Uso:
     python src/15_interseccion_pacientes.py <rnaseq_con_caso.tsv> <cnv_con_caso.tsv> <meth_con_caso.tsv> <salida.tsv> [n_max]
   Sin el argumento opcional n_max, guarda la lista COMPLETA de candidatos (ordenada alfabeticamente); con n_max, guarda solo los primeros n_max casos. Este comportamiento opcional (parametro final que cambia el resultado, comportamiento por defecto documentado) sigue el mismo patron ya usado en src/02c_filtrar_manifest_metilacion.py.
   La version v1 (interseccion.py, sin el filtro Primary Tumor ni el desempate) quedo obsoleta en el Paso 25 (daba una cifra preliminar de 458 candidatos en LUAD, incorrecta); se ha descartado.

3. src/16_generar_manifests_coordinados.py (a partir de generar_manifests.py, sesion ad-hoc, sin cambios de logica)
   A partir de una seleccion de pacientes (salida de 15_interseccion_pacientes.py) y el manifest completo de una cohorte, genera los 3 manifests filtrados en formato GDC (id, filename, md5, size, state) listos para descargar con tools/gdc-client.exe. Uso:
     python src/16_generar_manifests_coordinados.py <manifest_full.txt> <seleccion.tsv> <out_rnaseq.txt> <out_cnv.txt> <out_meth.txt>

4. src/17_verificar_coordinacion.py (AMPLIADO respecto a la version ad-hoc verificar_coordinacion.py de los Pasos 25-28)
   Verifica, sobre las 3 tablas finales ya generadas de una cohorte, que comparten exactamente los mismos pacientes Y que los 200 tienen muestra "Primary Tumor" consistente en las 3 modalidades. A diferencia de la version anterior (que solo comparaba los case_id de las cabeceras contra un fichero de seleccion previo, confiando en que ese fichero reflejara lo realmente descargado), esta version vuelve a consultar la API del GDC directamente sobre las cabeceras de las 3 tablas finales, sin depender de ningun fichero de seleccion. Esto es exactamente lo que se necesitaba para detectar el problema de BRCA por si solo, cosa que la version anterior no hacia. Uso:
     python src/17_verificar_coordinacion.py <rnaseq.tsv> <cnv.tsv> <meth.tsv>
   Devuelve codigo de salida 0 si case_id identicos Y Primary Tumor consistente en los 3; 1 en caso contrario (util para automatizar la comprobacion en el futuro).
